# Инструкция

Коротко: как запустить сайт, выложить его, добавить проект и поменять контакты. Отдельной админки нет. Правки делаются в файлах и попадают на сайт после перезапуска.

## Запуск локально

Нужен Node.js 20 или новее. Команды выполняются из папки `site`.

```powershell
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

Проверка перед выкладкой:

```powershell
npm run lint
npm run build
```

## Выкладка

Сайт работает как Node-приложение, не как набор статических файлов.

```powershell
npm run build
npm run start
```

Публичный адрес задаётся до сборки. Создайте `site/.env.local`:

```
NEXT_PUBLIC_SITE_URL=https://ваш-домен
```

После смены адреса соберите проект заново: переменная вшивается в сборку. Пока переменная пустая, превью для соцсетей собирается без постоянного домена. Образец переменной лежит в `.env.example`.

Подойдёт любой хостинг, где можно выполнить `npm run build` и держать процесс `npm run start`.

## Тексты и языки

Интерфейс переключается кнопками RU и EN в шапке. Выбор запоминается в браузере.

Все подписи интерфейса — в `src/lib/copy.ts`. Английский блок должен повторять набор полей русского: если поле есть только в одном языке, сборка не пройдёт.

## Новый проект на витрине

1. Положите кадры в `public/work/`. Имена латиницей, например `public/work/atelier-1.png`.
2. Добавьте объект в массив `projects` в `src/lib/projects.ts`.

Поля:

- `slug` — адрес страницы, латиницей, через дефис. Страница будет `/work/slug`
- `category` — одно из `landing`, `bot`, `system`, `automation`, `product`, `data`
- `featured: true` — карточка попадёт на первый экран. Без этого флага она видна только на витрине
- `year`, `title`, `summary`, `task`, `built`, `outcome`, `format`, `timeline` — тексты с полями `ru` и `en`
- `stack` — список технологий
- `frames` — кадры. Пустой массив `[]` оставляет на карточке букву вместо снимка

Пометка «Демо» рисуется сама, в данные проекта её писать не нужно. Учебные разборы ставьте в категорию `data`: на витрине они идут отдельным списком.

Базы заявок на сайте нет.

- Черновик анкеты живёт в `localStorage` браузера, пока человек не отправит форму.
- Отправка открывает чат https://t.me/Zolotaya79 с готовым текстом.
- Вторая кнопка готовит такое же письмо на почту из `src/lib/site.ts`.

Вилок бюджета в анкете нет. Стоимость называется после оценки задачи.
